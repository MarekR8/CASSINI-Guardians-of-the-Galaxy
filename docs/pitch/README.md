# Demo outline

For Challenge 2, show how the flood observation informs an evacuation decision. Identify the source and observation time of the Copernicus layer and label simulated closures and traffic.

Use the [flood scenario in the project overview](project-one-pager.md). Compare phased, coordinated departures with simultaneous departures to the nearest eligible shelter under the same conditions.

1. Show the flood layer, corridors, shelters and the group awaiting assisted pickup.
2. Close a bridge during the simulation. Show the affected routes and reservations, and the proposed changes to the next phase.
3. Show coordinator approval and track which updated instructions still need delivery.
4. Compare people remaining in affected zones over time, peak corridor queues, zone clearance times and assisted pickup waits.
