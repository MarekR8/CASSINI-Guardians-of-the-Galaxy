# Sentinel‑1 · Valencia 2024

The two GeoTIFFs are the matching crops used in the demo. They contain visualised VV gamma0 imagery exported from Copernicus Browser in UTM 30N (EPSG:32630). Both share a pixel grid of 1250 × 858. Each file is an 8-bit visualisation for display and manual annotation.
