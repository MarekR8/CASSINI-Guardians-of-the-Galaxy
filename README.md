# CASSINI-Guardians-of-the-Galaxy

An MVP for coordinating civilian evacuation during a flood. The demo follows a hazard alert, routes a pedestrian out of the affected area, dispatches assistance, and revises affected instructions after a bridge closure.

Start with the [MVP implementation guide](docs/mvp-implementation-guide.md). It links the [technology stack](docs/mvp-technology-stack.md), [service interfaces](docs/mvp-interfaces.md), [data and state design](docs/mvp-storage-and-state.md), and [demo fixtures and acceptance tests](docs/mvp-routing-and-demo.md).
