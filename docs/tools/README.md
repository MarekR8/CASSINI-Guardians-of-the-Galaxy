# Tools and data sources

The [Miro board](https://miro.com/app/board/uXjVEIhlQP4=/) is the team's working reference. The initial list below comes from the [one-pager](../pitch/project-one-pager.md) and the Participant Playbook, especially the space programme overview on pp. 11?12 and the FlyPix example on p. 23.

| Technology | Proposed use |
| --- | --- |
| Copernicus EMS | Obtain a flood extent layer with a source and observation time. |
| FlyPix AI | Evaluate optional Earth observation analysis, such as detecting features or changes in imagery. |
| OpenStreetMap | Prepare the pedestrian and road network. |
| Galileo and EGNOS | Explore position and accuracy on compatible devices. Use simulated reports for the first demo. |
| IRIS² | Consider future connectivity for equipped coordination points. Model outages in the prototype. |

Add one note per tool when the team has something concrete to record, such as the selected input, export format or an integration decision.
